# Machine Learning - CNN Models

Kho lưu trữ này chứa mã nguồn (Notebook) và hình ảnh thiết kế kiến trúc của các **mô hình CNN** chạy trên bộ dữ liệu **CIFAR-10**. Nội dung bao gồm các bài tập ví dụ lúc học và đồ án cuối môn.

## 📂 Danh sách các file trong Repository

* `Model_2.png` — Sơ đồ kiến trúc mạng CNN Model 2.
* `Model_3.png` — Sơ đồ kiến trúc mạng CNN Model 3.

* `cifar10_example1.ipynb` — Bài tập ví dụ mẫu 1.
* `cifar10_example2.ipynb` — Bài tập ví dụ mẫu 2.

### 🎓 Mã nguồn đồ án / Mô hình chính (Main Models)

* `cifar10_Model2.ipynb` — Code xây dựng và huấn luyện Model 2.
* `cifar10_Model3.ipynb` — Code xây dựng và huấn luyện Model 3.

## 🚀 Công nghệ sử dụng
